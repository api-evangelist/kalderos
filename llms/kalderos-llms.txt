# Kalderos

> Kalderos is a Chicago-based healthcare technology company (founded 2016, acquired by Model N in 2024) that built the first Drug Discount Management platform. It helps pharmaceutical manufacturers, covered entities, and state Medicaid programs manage compliance across U.S. drug discount programs — most notably 340B — identifying noncompliant or duplicate discounts and moving rebates transparently between stakeholders. Marquee products include 340B Pay, the Truzo rebate-payment platform, Discount Hub, and MDRP / Commercial Discount Monitoring.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Kalderos surface. Kalderos publishes no public OpenAPI — the former developer portal at api-docs.kalderos.com no longer resolves following the Model N acquisition. The customer application lives behind authentication at app.kalderos.com and API access is documented for customers via the help center's API Guide.

## Products
- [Manufacturers](https://www.kalderos.com/products/manufacturers): Solutions for pharmaceutical manufacturers
- [Covered Entities](https://www.kalderos.com/products/covered-entities): Solutions for safety-net healthcare providers
- [States](https://www.kalderos.com/products/states): Solutions for state Medicaid programs
- [MDRP Discount Monitoring](https://www.kalderos.com/products/mdrp-discountmonitoring): Medicaid Drug Rebate Program discount monitoring
- [Commercial Discount Monitoring](https://www.kalderos.com/products/commercial-discountmonitoring): Commercial discount monitoring
- [Discount Hub](https://www.kalderos.com/products/discount-hub): Good-faith-inquiry resolution for covered entities
- [Truzo](https://gotruzo.com/): End-to-end 340B rebate-payment platform
